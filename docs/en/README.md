# EduBoolean – English course

Welcome to EduBoolean.

This course is for complete beginners. No previous knowledge of Boolean algebra, digital electronics, programming or computer architecture is required.

We start with familiar ideas such as **yes/no**, **on/off** and **true/false**, then build step by step toward logic gates, digital circuits and the way computers use Boolean logic.

Norwegian is the primary course language. The English version is maintained as a parallel edition and should follow the same learning objectives and structure.
