# 53 – Sammenligninger lager boolske verdier

Uttrykk som:

```text
temperature > 30
count == 0
name != ""
```

produserer en sannhetsverdi.

Python:

```python
too_hot = temperature > 30
```

C:

```c
bool too_hot = temperature > 30;
```

Vanlige sammenligninger:

- lik
- ulik
- mindre enn
- større enn
- mindre enn eller lik
- større enn eller lik

## Ikke forveksle sammenligning og tilordning

I mange språk er:

```text
=
```

tilordning, mens:

```text
==
```

tester likhet.
