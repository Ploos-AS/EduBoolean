# 38 – Shift-register

Flip-flopper kan kobles slik at data flyttes én posisjon for hver klokkehendelse.

Eksempel:

```text
før:  1 0 1 1
etter: 0 1 0 1
```

avhengig av skiftretning og hvilken ny bit som mates inn.

Shift-registre brukes blant annet til:

- seriell ↔ parallell konvertering
- bitforskyvning
- forsinkelseslinjer
- enkelte kommunikasjonsgrensesnitt

Det viktige er at vi nå kombinerer **lagring** og **kontrollert bevegelse av bits**.
