# 55 – if: boolsk verdi styrer programflyt

En `if` velger om kode skal utføres basert på en betingelse.

Python:

```python
if temperature > 30:
    print("For varmt")
```

C:

```c
if (temperature > 30) {
    printf("For varmt\n");
}
```

Kombinerte betingelser følger samme logikk som før:

```python
if door_closed and key_valid:
    unlock()
```

Den boolske funksjonen er ikke lenger koblet til en fysisk utgangsport. Den styrer hvilken kodebane programmet tar.
